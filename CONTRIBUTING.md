# Feedback and contributions

Report reproducible bugs with the plugin version, IDE build, operating system and sanitized steps to reproduce. Use fictional issue contents and example domains. Never attach PATs or unredacted corporate screenshots/logs.

Describe feature requests in terms of expected behavior. Keep pull requests focused and document relevant verification. Build with `python3 build.py`; do not include build output, credentials or obfuscation maps in pull requests.

Contributions are provided under the MIT License. Submit only code you have permission to contribute.
